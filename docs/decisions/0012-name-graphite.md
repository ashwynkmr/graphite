# 0012. Name: Graphite
2026-10-31 · Accepted · Planning · Product

## Context
The app needed a name before the repo, URL and icon could exist. The product brief called for something minimal and elegant that feels like a well-made notebook, not a game.

## Options
- **A GRE-literal name:** clear, but generic and reads like every other prep tool.
- **A playful or gamified name:** at odds with the calm, test-condition design.
- **Graphite:** the pencil you study and take notes with.

## Decision
Graphite. The name sets the visual identity: warm paper background, graphite-grey text, one ink-blue accent, serif headings, faint ruled lines on cards, index-card flashcards and pencil-tick marks on results. The repo is `ashwynkmr/graphite` and the URL is `ashwynkmr.github.io/graphite`.

## Trade-offs
It doesn't say "GRE" or "math", so the purpose isn't obvious from the name alone. That's acceptable: the app is shared by link between two people, not found through search or an app store.

## Signals to revisit
- The app is ever opened up to more users who'd need to find it by search.
